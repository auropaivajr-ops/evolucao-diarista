# Evolução do Diarista

App de página única que monta a avaliação do intensivista diarista a partir de evolução, balanço hídrico e exames colados do prontuário.

Roda inteiramente no navegador: sem IA, sem internet e sem enviar dados. Não contém dado de paciente (o caso de exemplo é fictício).

O conteúdo anterior deste repositório (declaração de óbito) continua no histórico do Git.
